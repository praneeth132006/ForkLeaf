# Security Policy

## Supported Versions

Currently, mdnotion is in active early development. Only the `main` branch and the latest released versions are supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v0.x.x  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of mdnotion very seriously, especially given our commitment to "zero-knowledge" content storage. 

If you discover any security vulnerability in mdnotion—especially related to GitHub token handling, cross-site scripting (XSS) within the markdown renderer, or the collaborative editing server—please do not report it through public GitHub issues.

Instead, please send an email to the project maintainers directly or use GitHub's private vulnerability reporting feature on the repository.

Please include:
- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact of the vulnerability.

We will acknowledge your report within 48 hours and provide an estimated timeline for the fix. Once the vulnerability is patched, we will publicly disclose the vulnerability and appropriately credit you for the discovery.
