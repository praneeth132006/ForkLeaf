# Getting help

- **Documentation:** <https://www.forkleaf.in/docs> covers every part of the app, including troubleshooting and an FAQ.
- **Questions and ideas:** [GitHub Discussions](https://github.com/praneeth132006/ForkLeaf/discussions).
- **Bugs and feature requests:** [open an issue](https://github.com/praneeth132006/ForkLeaf/issues/new/choose).
- **Anything private** (your account, your data): email [support@forkleaf.in](mailto:support@forkleaf.in). Replies can land in spam, so check there if you haven't heard back within a couple of days.
- **Security vulnerabilities:** please report privately, as described in [SECURITY.md](SECURITY.md).
